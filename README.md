# DocuMind AI

**Your Intelligent PDF Question Answering Assistant**

> 📖 **First time running this project?** Check out the step-by-step [**Quick Start & Run Guide (RUN_GUIDE.md)**](file:///c:/Users/Jayesh/OneDrive/Desktop/RAG%20application/RUN_GUIDE.md) for Windows, macOS, and Linux setup instructions!

A production-grade, full-stack Retrieval-Augmented Generation (RAG) web application built with **React**, **Vite**, **Tailwind CSS**, **FastAPI**, **LangChain**, **FastEmbed**, **Qdrant (in-memory)**, and **NVIDIA NIM (Nemotron 3.5)**, backed by **MongoDB Atlas** for document metadata and interaction history.

---

## Key Features

- **Document Ingestion & Chunking**: Upload PDF documents with instant validation, page-aware text extraction via `PyPDFLoader`, and character splitting (`chunk_size=600`, `chunk_overlap=80`).
- **In-Memory Vector Search**: Local dense vector embedding via `FastEmbedEmbeddings` (`BAAI/bge-small-en-v1.5-onnx-Q`, 384 dimensions) and mathematically isolated indexing per document in `Qdrant`.
- **Mode 1 — Ask by Question Number**: Automatically locates question headers (e.g. `Q1.`, `Q.1)`, `Question 1:`, `1.`, `1)`), extracts multi-line question text, retrieves grounded context, and synthesizes answers.
- **Mode 2 — Ask Anything**: Free-text query interface for open-ended study, exam revision, or conceptual questions.
- **Grounded Academic Tutor**: Answers generated by NVIDIA NIM (`nvidia/nemotron-3.5-lightning-30b-a3b`) with source excerpts and page citations.
- **MongoDB Atlas Integration**: Persists document records, processing status, and question-and-answer history with in-memory fallback for local development.


## Environment Configuration

### Backend (`backend/.env`)

Copy `backend/.env.example` to `backend/.env`:

```env
# NVIDIA API Key (Required for LLM generation)
NVIDIA_API_KEY=nvapi-your-key-here

# MongoDB Atlas Connection String (Optional)
# MONGODB_URI=mongodb+srv://<user>:<password>@cluster0.mongodb.net/documind?retryWrites=true&w=majority

# CORS Origins
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

> [!IMPORTANT]
> The backend `.env` file contains your private API key and is ignored by Git. Never commit `.env`.

## Running the Application

### Step 1: Start the Backend Server

From the project root:

```powershell
$env:PYTHONPATH="."
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --reload --port 8000
```

The API will be available at:
* Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
* Health Check: [http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)

### Step 2: Start the Frontend Development Server

In a new terminal:

```bash
cd frontend
npm run dev
```

The frontend will be running at [http://localhost:5173](http://localhost:5173).

## Using DocuMind AI

1. **Active Document**: `STATS.pdf` in `document_loader/` is preloaded on backend startup. You can also drag-and-drop any PDF up to 25MB via the **Documents** tab.
2. **Ask by Question Number**:
   * Switch to the **Ask by Question Number** tab.
   * Enter a number such as `1`, `2`, or `5`.
   * Click **Find and Answer Question**.
   * DocuMind extracts the exact question text from the document and generates a grounded response.
3. **Ask Anything**:
   * Switch to **Ask Anything (Free Text)**.
   * Type any question (e.g., *"What are the normal equations for least squares?"*).
   * Press **Enter** or click **Ask Question**.
4. **View History**:
   * Click the clock/history icon in the top header to open the **Interaction History** drawer.
   * Click any saved interaction to reload its answer and evidence.

## Security Considerations

- **Secrets Isolation**: API keys and database credentials reside exclusively on the backend in `.env` files.
- **Frontend Safety**: The frontend never communicates directly with NVIDIA NIM or MongoDB.
- **Git Protection**: `.gitignore` is configured with comprehensive rules to prevent accidental commits of `.env`, `.venv`, and `node_modules`.
